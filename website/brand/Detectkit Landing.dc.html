how it works

Three pieces, one project tree.

SELECTnumpy[]
// query
SQL → time series
Any query on ClickHouse, PostgreSQL or MySQL becomes a metric. No SDK, no agents — your warehouse is the source of truth.
// detectors
Z-Score · MAD · IQR
Robust statistics learn a corridor of normal — with seasonality, trends and recency weighting — and flag the step outside it.
// channels
Slack · Mattermost · TG
Direction-aware quorum, cooldown, recovery and no-data alerts — posted with the rule that fired up top and evidence below.
dtk run

Load → detect → alert, in one command.

Idempotent and resumable: it picks up from the last saved point, so a cron every five minutes just works.

LOAD
Run the SQL on your warehouse, in batches, from the last checkpoint.
DETECT
Each detector scores points against its learned corridor of normal.
ALERT
Quorum met → post to chat with the rule up top, recovery on the way back.
